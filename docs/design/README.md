# Design references

The HTML prototypes Navo is built from, exported from the design tool. Open them in a
browser alongside `support.js` and `image-slot.js` (the prototypes load both).

| File | What it is |
|---|---|
| `Navo_Prototype.dc.html` | **The primary design.** Presenter panel, the joiner's phone (all 20 screens), HR owner console, agent runtime panel, guided demo, intro and outro. The app in `src/ui/` implements this. |
| `NavoFace.dc.html` | The Navo face persona and its nine states (`src/ui/components/NavoFace.tsx`). |
| `Navo_v2.dc.html`, `Onboarding_Agent_v3.dc.html` | Earlier iterations, kept for reference. |
| `Navo_Flow_Board.dc.html`, `Journey_Directions.dc.html` | Flow board and journey exploration boards. |

Halden is a fictional company. These files contain no real brands; keep it that way.
