# Demo Video Script — Target 3 to 4 Minutes

## 0:00–0:20 — Problem

"Joining a large organisation means coordinating HR, IT, managers, documents, training and access. The employee ends up becoming the project manager of their own onboarding."

## 0:20–0:40 — Product

"Our idea is an AI onboarding agent that takes ownership of that journey. It understands what is complete, what is blocked, who owns the next step and what it can do automatically."

## 0:40–1:15 — Employee home

Show:
- current Day-1 state
- one action needed from employee
- agent-handled items
- active risk

Explain that the UI is intentionally attention-first.

## 1:15–2:10 — Agentic event

Start with Employee ID delayed.

Show:
- dependency detection
- risk evaluation
- HR follow-up tool action
- activity log

Advance simulated time.

Show Employee ID arriving.

Show automatic laptop request.

## 2:10–2:40 — Policy Q&A

Ask:
"Can I work from home on Friday?"

Show grounded answer based on synthetic policy + user context.

## 2:40–3:00 — Day 1

Show personalised schedule and relevant policy cards.

## 3:00–3:30 — Technical architecture

Show:
- UI
- agent orchestrator
- state engine
- policy retrieval
- tools
- mock HR/IT/calendar systems
- persistence
- guardrails

## 3:30–3:50 — Value

Close with:

"Instead of asking employees to manage ten onboarding tasks, the agent manages the workflow and brings the employee in only when human judgement or input is actually required."

## Important

Do not spend most of the video on UI animations.

The most important proof is:
Observe → Decide → Act → State change → Communicate
