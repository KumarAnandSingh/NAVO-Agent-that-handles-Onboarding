# Design brief (persistent)

Design an AI agent, not an HR portal. The employee should see only what requires their attention while the agent handles, tracks and orchestrates the rest. Prioritize clarity, trust, progressive disclosure, proactive actions and visible state changes. Keep the visual language calm, premium and enterprise-grade, with restrained AI styling.

Keep the visual system calm and premium, but make the AI feel distinctly intelligent through interaction rather than decorative AI visuals. Avoid excessive gradients, glowing robot illustrations, floating AI orbs, and generic chatbot aesthetics. The product should feel like a trusted enterprise operating layer, not an AI toy.

Employee UI hierarchy (not dense): What needs me? → What is the AI handling? → What is blocked/risky? → What happens next? Everything else is secondary.

Agent Activity is contextual (attached to the item it affects), never a separate primary destination.

Visual: calm enterprise, light cool, accent #2F5BEA, neutral grotesk (Helvetica Neue). Agent voice: crisp operator. Product name: Navo. Tagline (logo lockup): "AI That Handles Onboarding". Descriptor when explaining what it is: "an AI onboarding agent" / "your AI onboarding agent". Supporting line: "Navo understands what's next, coordinates the work and steps in when needed." Action copy: "Ask Navo", "Let Navo handle it", "Navo is handling this", "Navo handled this", "Navo needs your input". Never repeat AI labels ("AI-powered", "AI assistant", "chatbot") or put "AI Agent" next to Navo on every screen; show intelligence through actions, company Halden (fictional). Synthetic data only. Agent signal color: cyan glow #38BDF8, used ONLY on agent-active states (live pill, in-progress step, critical path), never decorative.

Persona: Navo is a character, a small white screen-face robot with an N identity and expressive cyan eyes (NavoFace.dc.html). States: brand, calm, watching, thinking, acting, waiting, concerned, needs, celebrating. It lives inside the product (headers, story lines, risk cards), sized 18–40px in UI. Sophisticated, not cartoonish. Navo acts first; chat is secondary. Actor language: YOU (solid red dot), NAVO (face), DONE (green check), WAITING (amber ring). Core principle: "Navo doesn't show me my onboarding. Navo takes care of my onboarding." Journey is continuous: Application → Screening → Assessment → Interview → Selection → Offer → Documentation → Pre-joining → Day 1 → First week → 30/60/90, and Navo remembers earlier events.

Directions explored: 1 Command Centre (Now / Waiting / Done), 2 Journey (Offer → Pre-joining → Day 1 → Week 1 timeline with AI interventions), 3 Agent-first (proactive cards, state always visible). Leaning: Direction 1 + elements of Direction 2.
